**Контрольні запитання**
1. Що таке клас та об’єкт? Яка між ними різниця?

клас - це креслення або шаблон, за яким створюються об’єкти. об'єкт це конкретний екземпляр (представник) класу. якщо клас студент - це шаблон, то об’єкти - це конкретні студенти: Іван Петренко, Марія Сидоренко. Кожен об’єкт має свої власні значення полів.

2. Для чого використовуються конструктори? Чи може клас існувати без них?

конструктор використовується для початкової ініціалізації даних об'єкта під час створення через new. варіанти конструкторів можуть бути такими: за замовчуванням, параметризований, та перевантаження конструкторів

так, я думаю, що клас може існувати без явно написаного конструктора тому що, у такому разі C# автоматично створює стандартний конструктор за замовчуванням.

3. Чим відрізняється приватне поле від публічної властивості? Навіщо потрібна інкапсуляція?

приватне поле (private) зберігає дані всередині класу і недоступне ззовні, а публічна властивість (public) надає контрольований доступ до цього поля через блоки get та set. Інкапсуляція потрібна для приховування внутрішньої реалізації та захисту даних від некоректного змінення ззовні.

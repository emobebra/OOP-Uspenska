# Лабораторна робота №13

## Варіант 3

**Виконала: Успенська Емілія**

**Тема**: Власні винятки та патерн Result.

**Мета**:Навчитися створювати власні типи винятків для специфічних помилок, а також реалізовувати патерн Result для більш контрольованої обробки помилок без використання винятків у “нормальних” сценаріях невдачі.

## Короткий опис структури

у програмі реалізувала власний виняток InvalidFileFormatException для обробки файлів неправильного формату. створила узагальнений клас Result<T> з методами Success і Failure для повернення результатів операцій. у класі FileProcessorService реалізувала методи ReadFile та WriteToFile для читання й запису текстових файлів

### Висновки

у цій лабораторній роботі навчилася створювати власні винятки та використовувати патерн Result<T>. перевірила обробку помилок через try-catch і Result.Failure. власні винятки доцільно використовувати для особливих помилкових ситуацій, а Result<T> — для очікуваних помилок без викидання винятків

## Контрольні запитання

**1. Навіщо створювати власні типи винятків? Які переваги це дає?**

власні винятки потрібні для обробки конкретних помилок у програмі. вони дозволяють точніше визначати причину помилки та передавати додаткову інформацію

**2. Які стандартні конструктори рекомендується реалізовувати для власних винятків?**

рекомендується реалізовувати конструктор без параметрів, конструктор із повідомленням про помилку та конструктор із повідомленням і внутрішнім винятком

**3. Поясніть патерн Result. У яких випадках його використання є більш доцільним, ніж викидання винятків?**

патерн Result дозволяє повертати результат операції або повідомлення про помилку без використання винятків. його краще використовувати для очікуваних помилок, наприклад неправильних вхідних даних

**4. Які сценарії краще обробляти через винятки, а які через патерн Result?**

винятки краще використовувати для неочікуваних помилок, наприклад пошкодження файлу. Result підходить для очікуваних помилок, наприклад неправильного шляху до файлу або некоректних даних

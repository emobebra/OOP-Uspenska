# Самостійна робота №11

**Тема:** LINQ pipelines: ETL та аналітика.

Програма аналізує продажі за допомогою чотирьох LINQ-пайплайнів: найпопулярніші продукти за категоріями, дохід за містами, продажі за роками та місяцями, п'ятірка клієнтів за доходом у 2026 році.

Для тестування створюється 100 продуктів, 100 клієнтів і 1000 продажів. Генератор Random має фіксоване значення 11.

## Запуск

Відкрити термінал у папці IndependentWork11 і виконати:

dotnet run -c Release

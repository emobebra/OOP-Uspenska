**Тема**: LINQ: SelectMany, пагінація й custom extensions.

**Мета**:Навчитися використовувати оператор SelectMany для роботи з вкладеними колекціями, реалізовувати пагінацію даних за допомогою LINQ, а також створювати власні методи розширення для IEnumerable<T> або ключових доменних сутностей.

## Короткий опис структури

у програмі реалізувала систему обліку оцінок студентів з використанням LINQ. створила класи Student, Grade та Subject. оператор SelectMany використовується для об’єднання всіх оцінок в один список, Skip і Take для посторінкового виведення студентів, а власний метод розширення AverageScore() для обчислення середнього бала

### Висновки

у цій лабораторній роботі я навчилася працювати з вкладеними колекціями за допомогою SelectMany, реалізувала пагінацію студентів по 5 на сторінку та створила власний метод AverageScore(). у результаті програма виводить 36 оцінок, розподіляє 12 студентів на 3 сторінки та обчислює їхній середній бал

## Контрольні запитання

**1. Для чого використовується оператор SelectMany? Наведіть приклад, що демонструє його відмінність від Select.**

SelectMany використовується для об’єднання вкладених колекцій в один список. Select повертає окремі колекції, а SelectMany об’єднує їхні елементи. наприклад, усі оцінки студентів можна отримати в одному списку

**2. Як реалізувати пагінацію даних за допомогою LINQ? Які методи для цього використовуються?**

для пагінації використовуються методи Skip() і Take(). Skip() пропускає певну кількість елементів, а Take() вибирає потрібну кількість для однієї сторінки. У моїй програмі студенти виводяться по 5 на сторінку

**3. Поясніть концепцію методів розширення. Як вони інтегруються з LINQ?**

методи розширення дозволяють додавати нові можливості до наявних типів без зміни їхнього коду. вони оголошуються у статичних класах із використанням ключового слова this. Їх можна викликати для колекцій так само, як стандартні методи LINQ

**4. Наведіть приклад власного методу розширення для IEnumerable<T> та поясніть його призначення.?**

у моїй лабі створено метод AverageScore() для IEnumerable<Grade>. іін використовує Average() для обчислення середнього бала студента, і якщо список оцінок порожній, метод повертає нуль

## Контрольні запитання

**1. Поясніть різницю між синтаксисом запитів та синтаксисом методів у LINQ. Коли який краще використовувати?**

синтаксис запитів схожий на sql і використовує from, where, select. синтаксис методів використовує where(), select(), join(). перший зручніший для складних запитів, а другий для коротких операцій

**2. Для чого використовуються операції Join та GroupJoin? У чому їхня відмінність?**

join об'єднує елементи двох колекцій за спільним ключем. groupjoin групує пов'язані елементи. Наприклад, join об'єднує пост з автором, а groupjoin на автора з усіма його постами

**3. Наведіть приклади агрегуючих операцій LINQ та поясніть їхнє призначення.**

count() підраховує кількість елементів, sum() обчислює суму, average() середнє значення, min() мінімальне, max() максимальне значення

**4. Як можна виміряти продуктивність LINQ-запитів? Які фактори впливають на неї?**

продуктивність вимірюють за допомогою stopwatch, який визначає час виконання запиту, на швидкість впливають кількість елементів, складність запиту та тип операції
